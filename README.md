# edge_ai_yolo_on_esp32s3
本作品是一个基于ESP32S3的视觉边缘AI控制系统。系统集成了YOLO深度学习模型，能够对摄像头捕获的实时图像进行本地处理与分析，在电脑显示屏上精准绘制识别框。识别过程中需要连接wifi，使用站点模式。ESP32 作终端设备连接路由器/热点，和电脑处于同一局域网，通过 UDP 通信。本分支版本意在将芯片本地推理的结果可以显示到电脑上位机查看，而不是spi屏。

## 整体介绍
软件系统基于ESP-IDF v5.x框架开发，采用FreeRTOS实时操作系统进行任务调度。核心应用层包含五个主要模块。图像采集模块负责初始化摄像头、配置帧格式、创建帧队列和互斥锁，以及启动摄像头任务循环获取帧数据。模式管理模块维护系统的显示模式和检测状态，处理按键事件并触发相应的模式切换。AI检测模块加载YOLO11n模型到PSRAM，执行图像预处理、推理和结果解析，并调用绘制工具在图像上标注检测框。网络传输模块初始化WiFi连接，创建UDP Socket，将JPEG数据分片发送到电脑端。显示输出模块负责LCD屏幕的渲染和显示更新。
电脑端软件包含两个应用程序。第一个是基于OpenCV的简易查看器，通过UDP协议接收ESP32发送的JPEG图像流，实时解码并显示在窗口中，支持帧率统计和窗口缩放。第二个是基于PyQt5开发的图形界面应用，提供更美观的深色主题界面，支持自适应窗口大小、实时帧率和分辨率显示，以及连接状态指示。两个应用程序均通过配置文件读取网络参数，无需硬编码敏感信息。


### 1.1功能与特性
本系统核心功能是实现实时、准确的手语识别，并将其转化为点餐指令。用户通过摄像头拍摄手语，系统可在本地完成识别，并在上位机屏幕上实时显示识别结果。系统具备两种工作模式：通过短按Boot键可在“正常摄像头模式”与“AI检测模式”间切换；长按Boot键则可强制返回摄像头模式，操作便捷。整个系统完全离线运行，有效保护用户隐私，且功耗低，单次充电可持续工作约10小时。
### 1.2应用领域
本作品主要应用于餐饮服务行业，特别是快餐店、咖啡厅等需要快速点餐的场景，旨在消除聋哑顾客与服务人员之间的沟通障碍。此外，该技术框架也可扩展至其他需要手势交互的领域，如智能家居控制、工业设备操作等，为特殊人群提供更平等的社会参与机会。
### 1.3主要技术特点
1.边缘AI计算：采用ESP32-S3作为核心算力单元，所有AI推理均在设备端完成，无需云端支持，响应速度快且数据安全。 
2.轻量化模型部署：将YOLOv11n模型通过8位量化技术压缩近50%（从5.4MB至2.8MB），并成功部署于资源受限的MCU上，实现了高性能与低功耗的平衡。 
3.高度集成化设计：采用自研PCB板，将MCU、摄像头、显示屏等模块高度集成，系统结构紧凑，稳定性高。
