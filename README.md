# edge_ai_yolo_on_esp32s3
本作品是一个基于ESP32S3的视觉边缘AI控制系统。系统集成了YOLO深度学习模型，能够对摄像头捕获的实时图像进行本地处理与分析，在彩色显示屏上精准绘制识别框。整个识别过程无需联网，实现了高效的边缘计算。凭借ESP32S3强大的算力，系统不仅能完成目标检测，还能根据识别结果进行快速的智能决策与控制，为物联网应用提供了低延迟、高效率的视觉AI解决方案，展现了边缘计算在智能感知领域的巨大潜力。
# 摘要	
本作品是一款基于ESP32-S3的嵌入式边缘AI手语识别点餐控制系统，旨在为聋哑人群在餐饮场景中提供一种低成本、高可靠性的无障碍交互方案。系统以ESP32-S3双核MCU为核心，搭载OV2640摄像头与SPI接口LCD屏。软件层面，我们部署了经8位量化压缩的轻量化YOLOv11n模型，利用espdl框架在端侧完成图像采集、预处理、特征提取与手势分类的全流程本地化运算，无需依赖网络。系统通过Boot按键实现正常摄像与AI检测模式的切换，AI模式下识别延迟控制在200ms以内，并在屏幕上实时绘制识别框与标签。本作品成功验证了嵌入式边缘视觉AI在无障碍服务场景落地的可行性，为构建包容性社会提供了高效、低功耗的技术实践。
## 第一部分  作品概述
### 1.1功能与特性
本系统核心功能是实现实时、准确的手语识别，并将其转化为点餐指令。用户通过摄像头拍摄手语，系统可在本地完成识别，并在1.54英寸的LCD屏幕上实时显示识别结果。系统具备两种工作模式：通过短按Boot键可在“正常摄像头模式”与“AI检测模式”间切换；长按Boot键则可强制返回摄像头模式，操作便捷。整个系统完全离线运行，有效保护用户隐私，且功耗低，单次充电可持续工作约10小时。
### 1.2应用领域
本作品主要应用于餐饮服务行业，特别是快餐店、咖啡厅等需要快速点餐的场景，旨在消除聋哑顾客与服务人员之间的沟通障碍。此外，该技术框架也可扩展至其他需要手势交互的领域，如智能家居控制、工业设备操作等，为特殊人群提供更平等的社会参与机会。
### 1.3主要技术特点
1.边缘AI计算：采用ESP32-S3作为核心算力单元，所有AI推理均在设备端完成，无需云端支持，响应速度快且数据安全。 
2.轻量化模型部署：将YOLOv11n模型通过8位量化技术压缩近50%（从5.4MB至2.8MB），并成功部署于资源受限的MCU上，实现了高性能与低功耗的平衡。 
3.高度集成化设计：采用自研PCB板，将MCU、摄像头、显示屏等模块高度集成，系统结构紧凑，稳定性高。

### 1.5主要创新点
1.纯端侧无障碍交互方案：首次将YOLOv11n模型成功部署于ESP32-S3，实现了完全离线的、针对餐饮场景的复杂手语识别系统。 
2.高效的模型压缩与部署：通过8位量化和espdl框架，解决了大模型在微控制器上部署的难题，为边缘AI应用提供了新思路。
3.低成本与高集成度：通过自研PCB和选用低成本元器件，打造了一套经济实惠且性能可靠的解决方案，具备大规模推广潜力。
1.6设计流程
首先根据系统功能：摄像头画面传到显示屏，包括两种模式，先设计出软件架构，再根据硬件选型配备ov2640，lcd显示屏，以及自研pcb板，最后根据尺寸设计外壳。
